Saya adalah seorang IT Staff dan Junior Developer dengan spesialisasi pada pengembangan sistem aplikasi *low-code*[cite: 1]. Memiliki latar belakang kuat dalam desain grafis untuk pemasaran serta pemeliharaan infrastruktur IT dasar[cite: 1]. - 🚀 **Fokus Saat Ini**: Mendalami pengembangan game melalui **Godot Engine (GDScript)**[cite: 1], serta mengelola automasi sistem dengan **AppSheet** dan **Google Apps Script**.
